THE INTERNET FILES / INVESTIGATION 002

WHEN COMMUNITIES
WENT DARK.

An investigation into Reddit's 2023 API pricing controversy, the communities that protested, and the conflict between platform control and community power.

CASE NUMBER 002
CATEGORY Digital History
EVENT DATE June 2023
STATUS Published investigation
01 / OVERVIEW

THE STORY.

In 2023, Reddit announced changes to the way developers could access its application programming interface, commonly known as an API.

An API allows outside applications and services to communicate with a platform. Reddit's API supported third-party applications, moderation tools, and other community services.

The announced pricing changes caused significant disagreement among developers, moderators, and users. Many feared that the new costs would make popular third-party applications financially unsustainable.

On June 12, 2023, thousands of Reddit communities began restricting access or going private as part of a coordinated protest.

The central question: How did a disagreement about API access become a platform-wide community protest?

02 / BACKGROUND

UNDERSTANDING THE API CHANGES.

Reddit announced its API changes on April 18, 2023. The changes introduced a pricing structure for applications making large-scale API requests.

Reddit argued that providing large-scale API access created infrastructure and opportunity costs, and that commercial services using substantial amounts of its data should contribute financially.

Developers of third-party applications raised concerns about the proposed costs, the short implementation timeline, and the future of their products.

Reddit later stated that certain non-commercial moderation tools and qualifying accessibility applications would continue to receive access under specified arrangements.

03 / EVENT RECORD

THE TIMELINE.

APRIL 18, 2023

Reddit announces upcoming changes to its API access policies.

MAY 31, 2023

Reddit publishes additional API updates, including information about moderator access and enterprise-level pricing.

JUNE 8, 2023

News coverage reports that thousands of communities are planning to participate in a blackout beginning June 12.

JUNE 9, 2023

Reddit CEO Steve Huffman addresses community questions in an AMA while opposition to the API changes continues.

JUNE 12, 2023

The coordinated Reddit blackout begins. Communities restrict access or switch to private mode.

JUNE 15, 2023

Reddit publishes an explanation of its API updates and its position on the controversy.

JUNE 30, 2023

Reddit publishes further information about API rate limits and implementation.

Timeline dates are based on published announcements and reporting. The blackout did not end simultaneously for every participating community.

05 / INVESTIGATION

KEY FINDINGS.

01 — API access supported more than browsing.

Third-party applications and moderation tools depended on API access for functions beyond simply viewing Reddit posts.

02 — The pricing changes created widespread opposition.

Developers, moderators, and users raised concerns about application costs, accessibility, moderation, and the future of independent tools.

03 — Communities used their own access as leverage.

Participating moderators and communities restricted access to demonstrate opposition to the proposed changes.

04 — Reddit maintained its position on API pricing.

Reddit publicly defended its decision and described the financial and infrastructure reasons behind its policy.

These findings summarize the cited sources. They do not establish that every participating community shared the same motivations.

06 / CONCLUSION

THE BIGGER PICTURE.

The Reddit blackout demonstrated how dependent online communities can become on the platforms that host them.

It also showed that decisions about technical infrastructure can affect developers, moderators, accessibility, and ordinary users.

Reddit's API controversy was not simply a dispute about pricing. It became a wider disagreement about platform governance, community influence, and who controls the tools that make online communities function.

CASE 002 documents a major moment in digital community history: a platform policy change that led thousands of online communities to collectively restrict access in protest.
